# Evora Website

Official website of Evora.

## Technology Stack

- Astro (static output) + TypeScript + Tailwind CSS (decision D1, NVA-4)
- Hosting: Cloudflare Pages (D2), contact form via Pages Function (D3)
- Light theme, indigo palette, Space Grotesk + Inter (brand mini-kit v1.0, TBC-20 option a); English-only MVP (`lang="en"`), UI strings in `src/i18n/ui.ts` (PRD v0.4)

## Repository layout

- `src/` site source, `public/` static files served as-is (incl. `_headers`), `functions/` Pages Functions
- `aset/` design source files from high-fi (not deployed), see [aset/README.md](aset/README.md)
- `public/brand/` approved Evora brand assets (NVA-11), generated by `scripts/brand/build.mjs`, see [public/brand/README.md](public/brand/README.md)
- `docs/ops/` runbook

## Development

Requires Node 24 (`.nvmrc`) and pnpm via Corepack (`corepack enable`).

```bash
pnpm install
pnpm dev            # local dev server
pnpm run build      # static build to dist/
pnpm run preview    # serve dist/ + functions with wrangler (headers, 404, form)
pnpm run lint && pnpm run check && pnpm run format:check
```

## CI and contributing

- Every change goes through a branch and a pull request to `main`. Do not push directly to `main`.
- Workflow `ci` (job `verify`) runs on every PR and on `main`: `format:check`, `lint`, `check`, `build`, and Lighthouse CI. Merge only when `verify` is green and the branch is up to date (squash or rebase merge).
- Dependabot opens weekly update PRs for npm packages and GitHub Actions (`.github/dependabot.yml`).
- Branch protection on `main` is currently **not enforced** by GitHub (private repository on GitHub Free). The rules above are followed manually; see the runbook for the target protection settings.

## Deployment

Deploys are automated with GitHub Actions on Cloudflare Pages (project `evora`). Deploy jobs only run once the repo variable `CF_PAGES_ENABLED=true` and the Cloudflare secrets are set (runbook, "Prerequisites").

| Target     | How                                                                         | Workflow          |
| ---------- | --------------------------------------------------------------------------- | ----------------- |
| Preview    | Push to any branch other than `main` → `https://<branch>.evora.pages.dev`   | `preview.yml`     |
| Production | Merge a PR into `main` (or run the workflow manually via workflow_dispatch) | `deploy-prod.yml` |

Manual emergency deploy from an admin machine:

```bash
pnpm install --frozen-lockfile && pnpm run build
CLOUDFLARE_API_TOKEN=... CLOUDFLARE_ACCOUNT_ID=... \
  pnpm exec wrangler pages deploy dist --project-name=evora --branch=main
scripts/check-headers.sh https://<prod-url>
```

See [docs/ops/runbook.md](docs/ops/runbook.md) for prerequisites, rollback, headers, and monitoring.
